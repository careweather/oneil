# oneil-ts-interfaces

Generated TypeScript types for Oneil JSON wire formats (`TestReport`,
`RenderedTree`, and shared leaves such as `EvaluatedValue`).

Do **not** edit `src/generated/` by hand. From the repo root:

```sh
./scripts/generate-ts-interfaces.sh
./scripts/check-ts-interfaces.sh
```

See `docs/CODING_STANDARDS.md` (JSON Wire Types / Generated TypeScript Bindings).
